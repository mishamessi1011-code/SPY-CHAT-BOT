# Spy Chat Bot

Архив бизнес-чатов Telegram: сохраняет переписку и присылает владельцу удалённые
(и по желанию изменённые) сообщения — с фото, видео, голосовыми, кружочками, документами и стикерами.

## Подготовка (один раз)

1. **@BotFather** → ваш бот → *Bot Settings* → **Business Mode** → включить.
2. Нажмите `/start` у своего бота (иначе он не сможет вам писать).
3. Подключение: Telegram **Premium** → Настройки → **Telegram для бизнеса** → **Чат-боты** → введите @username бота.

## Тарифы

| | Бесплатно | ⭐ Премиум (100 ⭐ / 30 дней) |
|---|---|---|
| Уведомление «в чате удалили / изменили сообщение» | ✅ | ✅ |
| Текст и медиа удалённых сообщений | — | ✅ |
| «Было / стало» при редактировании | — | ✅ |
| /search, /export, /stats, /history | — | ✅ |

На бесплатном тарифе бот **не сохраняет** текст и медиа — только ID, автора и время сообщения
(чтобы не присылать уведомления о ваших собственных удалениях).
Все данные автоматически удаляются через `RETENTION_DAYS` (30) дней.

## Команды

| Команда | Что делает |
|---|---|
| `/settings` | уведомления, тихая ночь, скрытые чаты |
| `/premium` | тариф и покупка за Stars |
| `/privacy` | какие данные хранятся |
| `/delete_my_data` | удалить все свои данные |
| `/paysupport` | помощь с оплатой (обязательна по правилам Telegram) |
| `/search`, `/export`, `/stats`, `/history` | архив (Премиум) |
| `/admin`, `/backup`, `/givepremium id дни`, `/refund id charge_id` | админ |

## Деплой на mcweb.uz (fhost)

1. Создайте репозиторий на GitHub и загрузите туда файлы из этой папки
   (`.env` НЕ загружайте — он в `.gitignore`).
2. Новый проект → **Код: Git repository** → вставьте ссылку → «Проверить».
   Приватный репозиторий — через вкладку «GitHub».
3. **Тип приложения: Worker** (бот / фоновая задача).
4. Runtime — Python (определится по `requirements.txt`).
5. Тариф **Nano**.
6. Расширенные настройки:
   - команда запуска: `python spy_chat_bot.py`
   - переменные окружения — из `.env.example`
   - **постоянный диск (volume)** — обязательно. Если он смонтирован, например, в `/data`:
     `DB_PATH=/data/bot_archive.db`, `MEDIA_DIR=/data/media`.
     Без постоянного диска при каждом передеплое пропадут архив **и купленные подписки**.

## Деплой: обычный VPS (Ubuntu/Debian)

```bash
sudo apt update && sudo apt install -y python3 python3-venv
sudo adduser --disabled-password --gecos "" bot
sudo -iu bot
mkdir spy_chat_bot && cd spy_chat_bot        # сюда загрузите файлы
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env            # впишите BOT_TOKEN и ADMIN_IDS
venv/bin/python spy_chat_bot.py              # проверка; Ctrl+C чтобы остановить
exit
sudo cp /home/bot/spy_chat_bot/spy-chat-bot.service /etc/systemd/system/
sudo systemctl enable --now spy-chat-bot
journalctl -u spy-chat-bot -f                # логи
```

## Переход со старой версии

Просто положите старый `bot_archive.db` по пути `DB_PATH` — при первом запуске база
автоматически перенесётся в новую схему. Старые фото из `bot_media/` останутся рабочими,
если папка лежит рядом с ботом.

## Обслуживание

- Каждый день в `BACKUP_HOUR` админам приходит сжатый бэкап базы (медиа в него не входят).
- Каждый день в `CLEANUP_HOUR` удаляются все сообщения, правки и медиа старше `RETENTION_DAYS` дней.
- За 3 дня до конца Премиум и в день окончания бот присылает напоминание с кнопкой продления.
- При запуске/остановке и при ошибках бот пишет админам.
